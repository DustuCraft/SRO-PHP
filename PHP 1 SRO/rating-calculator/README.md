# Калькулятор рейтинга студента

Считает баллы по дисциплине и показывает для категорий «платник», «грантник» и «повышка», сколько не хватает до проходного балла, сколько нужно добрать до сессии и сколько набрать на самой сессии.

## Запуск

Нужен PHP 8.1+ (расширения не требуются).

```bash
php -S localhost:8000 -t public
```

Откройте http://localhost:8000. Тесты: `php tests/run.php`.

## Что показывает приложение

- Форма: по каждому компоненту (лекции, практика/лаборатория, сессия) можно ввести несколько оценок от 0 до 100 через пробел, запятую или `;`. Пустое поле означает, что оценок ещё нет.
- Доли компонентов заданы в `src/config.php`: лекции 0.1, практика/лаборатория 0.4, сессия 0.6. Баллы считаются по шкале 0–100.
- Проходные баллы категорий (`statuses` в конфигурации): платник 50 (без отчисления), грантник 70 (сохранение гранта), повышка 90 (повышенная стипендия).
- Проходной балл сессии 50 (`pass_min`): если он не набран, ни одна категория не сохраняется.
- До сессии: сколько баллов набрано из возможных и сколько ещё можно добрать.
- Для каждой категории: сколько не хватает до проходного балла, сколько нужно добрать до сессии, какой средний балл нужен на сессии и итог (сохраняется, достижимо, не сохраняется, добрать до сессии).
- История расчётов (последние 20) хранится в `var/data/history.json`.

## Как считаются цифры

- Набрано баллов: среднее по каждому компоненту умножается на его долю, результаты складываются; шкала держится в пределах 0–100.
- Не хватает до проходного балла: проходной балл минус набранные баллы.
- Не хватает до сессии: минимум, который нужно набрать до сессии, чтобы категория осталась достижимой даже при 100 баллах на сессии, минус то, что уже набрано до сессии. Если ноль, добирать не нужно.
- Нужно набрать на сессии: средний балл за сессию, при котором итог достигнет проходного балла (не ниже проходного балла сессии).

## Структура

| Путь | Назначение |
|---|---|
| `public/index.php` | Точка входа и контроллер |
| `public/assets/` | CSS |
| `src/` | Конфигурация, расчёт, история, помощники |
| `templates/` | PHP-шаблоны представления |
| `var/data/` | JSON с историей (вне публичного каталога) |
| `var/uploads/` | Зарезервировано под загрузки |
| `tests/`, `test-cases.md` | Автотесты и тестовые сценарии |
| `.gitignore` | Исключает историю, загрузки и секреты |

## Данные для демонстрации

| Лекции | Практика | Сессия | Результат |
|---|---|---|---|
| 80 | 70 | пусто | набрано 32,7; платнику на сессии не менее 50, грантнику не менее 68,4; повышке до сессии добрать 2,7 |
| 80 | 70 | 90 | 81,8: платник и грантник сохраняются, до повышки не хватает 8,2 |
| 100 | 100 | 45 | итог 70, но сессия ниже 50: ничего не сохраняется |
