# Тестовые сценарии

Автоматические проверки: `php tests/run.php`. Ручные сценарии ниже.

| № | Ввод (лекции / практика / сессия) | Ожидаемый результат |
|---|---|---|
| 1 | 100 / 100 / 100 | 100 баллов, статус «Повышка» |
| 2 | 80 / 70 / 90 | 81,8; платник и грантник сохраняются; до повышки не хватает 8,2; статус «Грантник» |
| 3 | 80 / 70 / пусто | Набрано 32,7 из 45,5 до сессии, можно добрать 12,7. Не хватает до проходных баллов: 17,3 / 37,3 / 57,3. На сессии: платнику не менее 50, грантнику не менее 68,4. Повышке до сессии добрать 2,7 |
| 4 | 100 / 100 / пусто | Добирать до сессии нечего; повышке на сессии не менее 81,7 |
| 5 | 100 / 100 / 45 | Итог 70, но сессия ниже 50: ничего не сохраняется, «Риск отчисления» |
| 6 | 100 / 100 / 50 | Проходной балл сессии достигнут, грантник сохраняется |
| 7 | 40 / 40 / 40 | «Риск отчисления» и предупреждение |
| 8 | 100 / пусто / пусто | Предупреждение: нет оценок по практике и сессии |
| 9 | 101 / 70 / пусто | Ошибка: 101 вне диапазона 0–100, расчёт не выполняется |
| 10 | abc / пусто / пусто | Ошибка: «abc» не число |
| 11 | все поля пустые | Ошибка: введите оценки хотя бы по одному компоненту |
| 12 | 50, 70 / 60 / 40 | Несколько оценок усредняются: 49,1 |
| 13 | Любой корректный расчёт, затем обновить страницу | Запись осталась в истории (JSON) |
| 14 | Кнопка «Очистить историю» | История пуста |
